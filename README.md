# Network Intrusion Detection System

## Project Description

This project implements a simple Network Intrusion Detection System using AI and Machine Learning techniques. The project includes:

- Data Exploration
- Simple Reflex Agent
- K-Nearest Neighbors (KNN)
- Naïve Bayes
- Logistic Regression
- K-Means Clustering
- Genetic Algorithm for Feature Selection

Dataset used: `network_traffic.csv`


## Requirements

Install the following Python libraries:

```bash
pip install numpy pandas matplotlib scikit-learn
```

## How to Run

1. Place `network_traffic.csv` in the same folder as the notebook.
2. Open the Jupyter Notebook.
3. Run all cells from top to bottom.
4. The notebook will:
   - Load and explore the dataset
   - Train and evaluate classifiers
   - Generate plots
   - Display confusion matrices
   - Run K-Means clustering
   - Run the Genetic Algorithm
